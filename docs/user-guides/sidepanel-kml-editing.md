# SidePanel 双屏 KML 编辑使用说明

## 1. 适用场景

使用 SidePanel 等浏览器侧栏工具时，可以把 map-service 固定在侧栏，在主页面查看资料或其他地图，并在侧栏中编辑自己的 KML。

## 2. 首次登录

1. 在 SidePanel 中打开 map-service 的地图地址。
2. 打开“KML 数据管理”。若显示“请先登录”，点击该状态进入登录页。
3. 在侧栏内完成登录。登录成功后会返回原地图并加载账号 KML。

浏览器会把侧栏会话与普通标签页会话分区保存，因此首次使用某个 SidePanel 扩展时可能需要单独登录一次。

## 3. 编辑与保存

- 登录后，新增、编辑、删除、排序、移动、复制和导入操作与普通标签页一致。
- KML 面板中的“保存中”“已保存”或“保存失败”表示账号同步状态。
- 侧栏可以随时关闭。存在未同步修改时，页面会保留该账号的恢复草稿；重新打开并登录同一账号后，按恢复提示处理。
- 不要在“保存失败”或“版本冲突”状态下直接丢弃恢复草稿，先按页面提示重试、加载服务器版本或另存冲突副本。

## 4. 安全与数据隔离

- 侧栏未登录时不会读取访客 KML，也不会开放个人 KML 编辑入口。
- map-service 不会把账号 Token、密码或 KML 数据发送给 SidePanel 父页面。
- 普通标签页退出登录不会替代侧栏内的退出操作；需要结束侧栏会话时，请在侧栏账号页面退出。

## 5. 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 登录后仍显示“请先登录” | 使用最新版 Chrome，允许该站点保存网站数据，然后在侧栏内重新登录 |
| 提示浏览器未能建立侧栏会话 | 确认服务使用 HTTPS；本机调试使用 `localhost` 或 `127.0.0.1`，不要使用普通局域网 HTTP 地址 |
| 重新打开后出现恢复提示 | 说明上次关闭前仍有未同步修改，选择恢复并等待同步完成 |
| 一直显示保存失败 | 系统会自动刷新一次侧栏会话并重试；仍失败时检查网络和登录状态，重新登录同一账号后按提示恢复草稿 |
| 只有查看权限 | 联系管理员为账号授予个人 KML 写权限 |
