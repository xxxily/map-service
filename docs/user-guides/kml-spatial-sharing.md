# KML 空间受限分享使用说明

> 适用版本：v1.5.34 及以上
> 适用对象：登录用户、分享访问者、管理员和超级管理员

## 1. 能力说明

登录用户可以在“个人空间 -> 我的分享”中，将一个或多个自己的 KML 组合为只读分享，并选择是否把地图浏览范围限制在这些 KML 坐标形成的外包矩形内。

启用“限制在 KML 区域”后，服务端会收集分享内全部有效 KML 的点、线、面坐标，取最小/最大经纬度对应的局部投影边界并在四边增加管理员设置的余量。外包矩形内部全部可查看，即使矩形内部没有实际点位、线段或面；访问者仍可查看点位详情、线路、面、媒体和 KML 管理面板。分享设置中可选填“范围外底图放宽到缩放级别”：该级别及更小缩放允许加载范围外周边底图，放大到更高层级后底图仍限制在外包矩形内；相机中心始终不能通过拖动离开 KML 外包矩形。

## 2. 创建空间受限分享

1. 登录后进入“个人空间 -> 我的分享”。
2. 创建分享并选择一个或多个 active KML。
3. 在“地图范围”中选择“限制在 KML 区域”。
4. 等待范围预检完成，确认面积、对角线和边界余量。
5. 按需设置分享密码、链接有效期和下载权限；只有管理员开放无密码分享时，才可选择“不设置密码”。
6. 如需低缩放周边底图，在“范围外底图放宽到缩放级别”填写不高于管理员配置上限的整数（基础范围 `0～24`，默认上限为 `14`）。该级别及更小缩放可显示周边底图，即使高于本次范围预检 `minZoom` 也可以保存；更高缩放立即恢复 KML 范围限制。留空表示所有层级都严格限制在 KML 范围内。
7. 保存后复制分享链接。

分享链接页面会使用“分享标题”和“分享说明”生成浏览器标题、链接预览标题和摘要；社交软件通常会识别 Open Graph/Twitter 卡片及地图分享预览图。预览地址会自动去除密码、坐标和图层参数，不会把这些信息展示在卡片中。

设置分享密码后，“复制链接”可选择：

- 普通链接：访问者需要手动输入密码。
- 带密码链接：不需再次输入当前密码，系统会将所有者已设置的密码加入一次性自动验证参数。访问页面会立即清理地址栏中的密码；以后修改分享密码，旧带密码链接将失效。
- 单独复制密码：可将普通链接和密码分开交付。

创建或更换密码时可点击“生成密码”。生成器默认生成 12 位密码，可选择 8、12、16、20、24 或 32 位，并可关闭特殊字符。启用特殊字符时使用 `!$*+@`，排除 `?`、`&`、`#`、`%`、`=` 等 URL 查询分隔符；最终带密码链接仍会对密码执行 URL 编码。

范围预检只用于当前界面反馈。保存时服务端会重新读取 KML 并校验，避免 KML 或后台策略在预检后已经变化。

## 3. 密码授权模式

设置分享密码后可选择：

- `按后台有效期`：验证密码后，在管理员配置的有效期内免重复输入。
- `不限固定期限`：不设置固定授权到期时间，但只适用于空间受限且范围符合后台阈值的分享。

“不限固定期限”不等于永久授权。分享暂停、撤销、封禁、到期、轮换链接、修改密码、关闭空间限制或策略不再合规时，服务端会立即撤销相关授权。清除 Cookie、更换浏览器或设备后也需要重新验证密码。

## 4. 半公开分享

当后台公开分享策略为“分享链接独立访问”，且管理员已开启无密码分享、分享未设置密码并启用了空间限制时，持有高熵分享链接的人可以直接查看受限区域。链接有效期可以设置为固定期限，也可以选择不限固定期限；此时密码授权显示为“不适用”。这适合开放小范围路线或点位信息，但不能确认访问者身份。

链接泄露后仍可能被他人访问。需要停止公开时，可暂停分享、轮换链接或撤销分享。

## 5. 访问者体验

- 打开链接后，地图自动适配服务端允许区域。
- 空间受限分享只使用 2D 地图；访问 `/3d` 会回到 2D 分享页。
- 搜索、历史、定位、路线规划、导入、编辑和重新分享入口不会在受限匿名分享中开放。
- 低于或等于放宽级别的范围外瓦片通过受控图源直接加载；更高层级完全位于允许区域内的瓦片正常显示，边界瓦片由服务端保留范围内像素并将范围外像素转为透明，完全越界的瓦片不会回源。
- KML 点、线、面、详情和媒体预览保持普通只读分享的交互。

## 6. 编辑与同步发布

- 修改已分享 KML 的点、线、面或说明后，个人空间会先保存当前版本，外部分享链接继续展示上一次已发布内容。
- “我的分享”会显示待同步 KML 数量。确认内容无误后点击“同步内容”，服务端才会更新公开快照并重新计算地图范围。
- 同步时若范围超过“不限授权”阈值但仍符合总体阈值，分享会按当前策略改为有限授权，已有不限授权会话被撤销。
- 同步时若范围超过总体阈值、没有有效几何或计算失败，本次同步失败，旧公开内容和旧范围继续可用，不会自动改成不受限分享。
- 修改 KML、范围重算失败或公开读取异常不会自动暂停分享。分享只会在所有者主动暂停、管理员封禁或所有者撤销时停止；暂停后恢复会沿用原分享设置和已发布快照。
- KML 移入回收站后不再产生新的可同步内容，但已发布快照和分享配置保留；恢复 KML 后可由所有者确认并再次同步。若不再需要链接，请删除分享而不是删除源 KML。
- 删除分享会清理分享链接、分享项、访问会话、访问记录和运行指标，不影响个人空间中的原始 KML；删除后旧链接立即失效。撤销与删除是不同操作：撤销保留可审计的停用记录，删除执行彻底清理。
- 当前没有正式用户，空间范围模型升级不迁移旧测试分享；遇到旧测试链接时直接删除分享并按新规则重新创建。

## 7. 管理员操作

具备分享治理权限的管理员可以在“分享治理”查看地图范围模式、范围状态、面积、对角线和密码授权模式，并按现有流程封禁或解除封禁。

超级管理员可在“用户体系设置”配置空间能力开关、边界余量、总体阈值、范围外底图放宽最大级别（默认 14）和不限授权阈值。保存空间策略前，后台会预览受影响分享、自动降级分享和待撤销不限授权会话数量，并使用统一确认弹窗要求确认。管理员下调放宽最大级别时，存量分享会自动将已保存值收敛到新上限。

具备用户体系安全设置权限的管理员还可以开启或关闭“无密码分享”。关闭后，不能新建无密码分享、移除已有密码，也不能继续保存、同步或轮换已有无密码分享；访问者是否能打开已经存在的链接不作为旧版本兼容目标，测试链接可删除后重建。

管理员还可以在同一设置页调整分享清单和瓦片限流。默认容量适用于连续缩放和多图层加载；范围外透明瓦片不消耗允许配额。分享治理页会显示限流摘要和用户分享的统计配置，管理员可逐分享禁用或恢复统计脚本。

全站统计支持填写不含内联代码的 HTTPS 外部 `<script>`。KML 分享统计默认使用管理员固定的托管服务，分享者只填写网站 ID；只有超级管理员明确开放后，分享者才能使用自定义外部脚本。

## 8. 访问记录与统计

“我的分享”中的“访问记录”展示最近 30 天的聚合访问情况，包括首次与最近访问时间、聚合次数、设备大类、来源站点和访问方式。系统不会在此记录原始 IP、完整浏览器标识或完整来源地址。

分享编辑页的“访问统计”选项受后台策略控制：

- 不启用：只保留系统内置的低敏聚合记录。
- 托管服务：填写第三方统计系统分配的网站 ID，脚本地址由管理员统一控制。
- 自定义脚本：仅在超级管理员开放后出现，只允许无内联代码的 HTTPS 外部脚本。

第三方统计脚本由对应服务自行处理数据。分享者在启用前应确认该服务的数据范围和隐私政策。

## 9. 常见问题

### 无法选择不限固定期限

确认已经设置分享密码、启用空间限制、范围预检成功，且面积和对角线都没有超过后台不限授权阈值。

无密码分享的链接不限固定期限是另一项设置，不创建密码授权会话；请确认管理员已开启无密码分享，并在“有效期”中选择“永不过期”。

### 分享提示范围过大

移除跨度过大的 KML、拆分分享或缩小 KML 内容范围。若明确需要浏览更大地图，可关闭空间限制，但密码授权必须使用有限模式。

### 地图边缘出现透明区域

边界以外像素会按空间授权规则保持透明，这是防止读取范围外底图的正常结果。若 KML 范围内也整片空白，请记录分享链接和发生时间交给管理员排查，不要在日志中复制密码查询参数。

### KML 修改后外部链接没有变化

这是发布保护的预期行为。进入“个人空间 -> 我的分享”，找到显示“待同步”的分享并点击“同步内容”。同步成功后外部链接才会读取新内容。

### 同步内容时提示范围不合规

新的 KML 内容可能为空、跨越范围过大、接近不支持的极区或超过管理员阈值。旧分享仍保持可用；调整 KML 后再次同步，或修改分享的空间访问与密码授权设置。

### 分享为什么没有因为 KML 修改而自动停止

这是为了避免尚未审核的编辑直接影响外部链接。链接继续展示最近一次成功同步的快照；确认内容后在“我的分享”执行“同步内容”即可发布。

### 连续缩放仍然收到 429

联系管理员检查“用户体系设置 -> 分享访问限流”及“分享治理”的限流事件摘要。正常访问应按浏览器匿名访客区分，只有已通过图源和空间校验的瓦片才计数。
