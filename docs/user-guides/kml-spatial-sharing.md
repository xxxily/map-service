# KML 空间受限分享使用说明

> 适用版本：v1.5.27 及以上
> 适用对象：登录用户、分享访问者、管理员和超级管理员

## 1. 能力说明

登录用户可以在“个人空间 -> 我的分享”中，将一个或多个自己的 KML 组合为只读分享，并选择是否把地图浏览范围限制在这些 KML 附近。

启用“限制在 KML 区域”后，服务端会根据分享内全部有效 KML 的点、线、面和管理员设置的边界余量计算允许区域。访问者仍可查看点位详情、线路、面、媒体和 KML 管理面板，但不能通过拖动、缩放、URL 参数或直接请求瓦片读取范围外地图。

## 2. 创建空间受限分享

1. 登录后进入“个人空间 -> 我的分享”。
2. 创建分享并选择一个或多个 active KML。
3. 在“地图范围”中选择“限制在 KML 区域”。
4. 等待范围预检完成，确认面积、对角线和边界余量。
5. 按需设置分享密码、链接有效期和下载权限。
6. 保存后复制分享链接。

设置分享密码后，“复制链接”可选择：

- 普通链接：访问者需要手动输入密码。
- 带密码链接：系统校验当前分享密码后，将密码加入一次性自动验证参数。访问页面会立即清理地址栏中的密码；以后修改分享密码，旧带密码链接将失效。

创建或更换密码时可点击“生成密码”，系统会在浏览器中生成包含大小写字母、数字和符号的高强度密码，并允许立即复制。

范围预检只用于当前界面反馈。保存时服务端会重新读取 KML 并校验，避免 KML 或后台策略在预检后已经变化。

## 3. 密码授权模式

设置分享密码后可选择：

- `按后台有效期`：验证密码后，在管理员配置的有效期内免重复输入。
- `不限固定期限`：不设置固定授权到期时间，但只适用于空间受限且范围符合后台阈值的分享。

“不限固定期限”不等于永久授权。分享暂停、撤销、封禁、到期、轮换链接、修改密码、关闭空间限制或策略不再合规时，服务端会立即撤销相关授权。清除 Cookie、更换浏览器或设备后也需要重新验证密码。

## 4. 半公开分享

当后台公开分享策略为“分享链接独立访问”，且分享未设置密码并启用了空间限制时，持有高熵分享链接的人可以直接查看受限区域。这适合开放小范围路线或点位信息，但不能确认访问者身份。

链接泄露后仍可能被他人访问。需要停止公开时，可暂停分享、轮换链接或撤销分享。

## 5. 访问者体验

- 打开链接后，地图自动适配服务端允许区域。
- 空间受限分享只使用 2D 地图；访问 `/3d` 会回到 2D 分享页。
- 搜索、历史、定位、路线规划、导入、编辑和重新分享入口不会在受限匿名分享中开放。
- 完全位于允许区域内的瓦片正常显示；边界或范围外瓦片使用透明占位，因此边缘可能出现空白，这是首期安全策略的预期表现。
- KML 点、线、面、详情和媒体预览保持普通只读分享的交互。

## 6. 编辑与同步发布

- 修改已分享 KML 的点、线、面或说明后，个人空间会先保存当前版本，外部分享链接继续展示上一次已发布内容。
- “我的分享”会显示待同步 KML 数量。确认内容无误后点击“同步内容”，服务端才会更新公开快照并重新计算地图范围。
- 同步时若范围超过“不限授权”阈值但仍符合总体阈值，分享会按当前策略改为有限授权，已有不限授权会话被撤销。
- 同步时若范围超过总体阈值、没有有效几何或计算失败，本次同步失败，旧公开内容和旧范围继续可用，不会自动改成不受限分享。
- KML 移入回收站后会从原分享中解除关联；恢复 KML 不会自动重新加入原分享。

## 7. 管理员操作

具备分享治理权限的管理员可以在“分享治理”查看地图范围模式、范围状态、面积、对角线和密码授权模式，并按现有流程封禁或解除封禁。

超级管理员可在“用户体系设置”配置空间能力开关、边界余量、总体阈值和不限授权阈值。保存空间策略前，后台会预览受影响分享、自动降级分享和待撤销不限授权会话数量，并使用统一确认弹窗要求确认。

管理员还可以在同一设置页调整分享清单和瓦片限流。默认容量适用于连续缩放和多图层加载；范围外透明瓦片不消耗允许配额。分享治理页会显示限流摘要和用户分享的统计配置，管理员可逐分享禁用或恢复统计脚本。

全站统计支持填写不含内联代码的 HTTPS 外部 `<script>`。KML 分享统计默认使用管理员固定的托管服务，分享者只填写网站 ID；只有超级管理员明确开放后，分享者才能使用自定义外部脚本。

## 8. 访问记录与统计

“我的分享”中的“访问记录”展示最近 30 天的聚合访问情况，包括首次与最近访问时间、聚合次数、设备大类、来源站点和访问方式。系统不会在此记录原始 IP、完整浏览器标识或完整来源地址。

分享编辑页的“访问统计”选项受后台策略控制：

- 不启用：只保留系统内置的低敏聚合记录。
- 托管服务：填写第三方统计系统分配的网站 ID，脚本地址由管理员统一控制。
- 自定义脚本：仅在超级管理员开放后出现，只允许无内联代码的 HTTPS 外部脚本。

第三方统计脚本由对应服务自行处理数据。分享者在启用前应确认该服务的数据范围和隐私政策。

## 9. 常见问题

### 无法选择不限固定期限

确认已经设置分享密码、启用空间限制、范围预检成功，且面积和对角线都没有超过后台不限授权阈值。

### 分享提示范围过大

移除跨度过大的 KML、拆分分享或缩小 KML 内容范围。若明确需要浏览更大地图，可关闭空间限制，但密码授权必须使用有限模式。

### 地图边缘出现透明区域

首期不会返回同时覆盖允许区和范围外区域的原始边界瓦片。放大地图或移动到 KML 内容附近即可获得更多完整瓦片。

### KML 修改后外部链接没有变化

这是发布保护的预期行为。进入“个人空间 -> 我的分享”，找到显示“待同步”的分享并点击“同步内容”。同步成功后外部链接才会读取新内容。

### 同步内容时提示范围不合规

新的 KML 内容可能为空、跨越范围过大、接近不支持的极区或超过管理员阈值。旧分享仍保持可用；调整 KML 后再次同步，或修改分享的空间访问与密码授权设置。

### 连续缩放仍然收到 429

联系管理员检查“用户体系设置 -> 分享访问限流”及“分享治理”的限流事件摘要。正常访问应按浏览器匿名访客区分，只有已通过图源和空间校验的瓦片才计数。
