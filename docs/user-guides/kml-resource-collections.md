# KML 资源集合使用说明

资源集合适合管理同一地点的多时期、多角度照片、视频、音频或全景页面。集合本身只占用一个地图点位，避免热门地点在地图上堆叠大量标记。

## 创建和编辑

1. 登录后打开 KML 数据管理，新增或编辑一个点位。
2. 将点位类型切换为“资源集合”，选择点位图标并保存集合。
3. 在集合编辑器中选择默认的卡片或列表视图，逐项填写标题、地址和类型；也可以一次粘贴多个 HTTPS 地址后再补充标题。
4. 使用上下移动按钮调整资源顺序，保存后集合仍保持该顺序。

编辑时，卡片和列表会同步改变编辑区布局：卡片适合逐项补充标题，列表适合快速检查和修改地址。点击“添加资源”会自动定位到新资源的地址字段；暂时没有填写任何内容的空白占位项会在保存时忽略，已填写标题或类型但没有地址的项会被标记并要求修正。批量粘贴框会在重绘和切换布局时保留内容，成功添加后自动清空，并跳过集合中已有的重复地址。

集合最多保存 300 项，单项标题最多 200 个字符，集合序列化数据最多 512 KiB。地址必须为 HTTPS，不能包含账号、密码或访问令牌等敏感查询参数；720 云的 `scene_id`、`view` 等普通视图参数会保留。

## 浏览资源

点击集合点位后先查看资源数量摘要，再打开集合面板。面板支持列表和卡片两种方式，每页最多显示 40 项。图片只在进入可见窗口时加载，视频、音频和页面不会在列表阶段创建播放器。

点击具体资源会进入统一媒体预览器，可使用上一项、下一项和缩略轨道浏览。关闭预览或集合面板后，播放器、页面和图片的临时资源会被释放。

无法在页面内预览的资源会保留为“打开原地址”入口，不会阻断其他资源的浏览。编辑器关闭前如果存在未保存修改，会先确认是否放弃。

## 分享和导入

集合随所属 KML 文件保存、导出和分享。分享访问为只读，访客可以浏览资源和打开预览，但不能修改集合结构。

导入标准 KML 时，合法集合会从 `map-service:resource-collection` 扩展字段恢复。非法 JSON、未知版本或超出限制的集合不会阻断整份文件，点位几何会保留，并在导入结果的 warning 中说明被忽略的原因；再次导出不会原样写回未知结构。

## 性能边界

未打开集合时，地图只加载集合点位图标和数量，不解析集合内的全部地址。即使一个集合包含 300 项资源，也不会在地图上常驻 300 个媒体节点。文件级媒体画廊默认不展开集合内容，只有进入集合或点击资源时才建立对应的预览数据。
