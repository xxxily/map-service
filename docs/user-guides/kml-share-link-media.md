# KML 点位分享链接媒体使用说明

## 支持范围

当前支持抖音公开视频分享链接和 720 云公开全景地址。系统只把经过固定 provider 规则校验的地址转换为 iframe；其他网页仍按普通链接处理。

抖音可以粘贴应用复制出来的完整分享文案，也可以粘贴以下地址：

- `https://v.douyin.com/<短码>/`
- `https://www.douyin.com/video/<视频 ID>`
- `https://www.iesdouyin.com/share/video/<视频 ID>`
- `https://open.douyin.com/player/video?vid=<视频 ID>`

720 云可以粘贴以下公开地址：

- `https://www.720yun.com/vr/<作品 ID>`
- `https://720yun.com/vr/<作品 ID>`
- `https://www.720yun.com/t/<嵌入 ID>`
- `https://720yun.com/t/<嵌入 ID>`

私密、已删除、下架、地区受限或平台不允许嵌入的内容可能无法播放。720 云地址只使用用户填写的公开页面，不读取登录态或私有作品数据。

## 添加到点位

1. 登录 map-service，并确认账号具有 KML 编辑权限。
2. 在 2D 或 3D 地图中新增点位，或打开已有点位后选择“编辑”。
3. 把抖音分享文案或 720 云地址粘贴到“描述”中，可以同时填写自己的说明文字。
4. 点击保存。系统会识别链接，并把可用视频或全景页面转换为点位媒体。
5. 打开点位弹窗中的媒体卡片或“查看详情”，即可在统一媒体预览器中查看。

抖音短链接需要服务端展开，通常会比普通点位保存多等待片刻；已经包含视频 ID 的详情地址和 720 云地址可以直接在浏览器本地转换，不需要服务端回源。

## 选择点位图标

新增或编辑 Point 点位时，可以在“点位图标”中选择“自动识别内容”或内置语义图标（观景、营地、餐饮、停车、相机等）。快捷栏保持单行横向滚动，低频图标可通过右侧“更多”打开完整图标库；最近成功保存的显式图标会在当前浏览器中优先显示。

- “自动识别内容”不写入数据：抖音、720 云和图片/视频/音频等媒体会自动显示对应图标。
- 选择内置图标后，手动图标优先于媒体类型和平台图标；再次选择“自动识别内容”即可恢复自动识别。
- 2D、3D、KML 管理列表、本地导出/导入和公开分享会保持同一图标。

点位名称不是必填项。留空保存后地图上只显示图标，popup、详情、媒体预览和 KML 列表不会显示“未命名点位”占位标题；列表仍会为屏幕阅读器保留“定位到未命名点位”的辅助名称。

## 预览显示

- 在手机或其他触屏优先设备上，单击带媒体的点位会直接打开图片、视频或页面预览；长按点位会打开原有简介弹窗，以便查看详情或执行编辑、删除、收藏等操作。电脑端仍先打开点位简介弹窗。
- 多项媒体的底部缩略轨道在移动端默认收起，可使用顶部缩略图图标展开；电脑端默认展开，也可使用同一图标收起。只有一项媒体时不显示该开关。
- 移动端打开媒体预览后，浏览器返回按钮或系统返回手势会先关闭预览，不会直接退出当前地图页面；使用关闭按钮的效果相同。
- iframe 水平方向会占满媒体预览区域，不再设置固定最大宽度或左右留白；当页面高度小于可用区域时，只做上下居中。
- 抖音播放器会按当前 iframe 视口自适应宽高。播放器主体和播放控制条完整保留，额外的白色底部跳转栏不再占用站内预览区域。
- 关闭媒体预览后，可以直接再次点击点位 popup 中的同一张媒体卡片重复打开，无需先关闭并重新打开点位 popup；收缩小窗、恢复和打开原始页面功能保持不变。
- 第三方页面内部的颜色和布局由对应平台控制，站点不会跨域修改其页面内容。平台加载失败时仍可使用“原始页面”前往查看。

## 编辑和删除

- 再次编辑点位时，只会看到原分享文案、自己的说明和图标选择，不会看到系统生成的 iframe 标记。
- 不修改分享链接直接保存时，会复用已有解析结果，不会重复添加媒体。
- 从描述中删除分享链接并保存后，对应媒体也会移除。
- 同一个平台资源链接出现多次，只展示一个媒体项。

## 失败处理

如果短链接超时、平台拒绝访问、内容不可用、账号未登录或没有写权限，点位仍会保存原始描述，并显示转换失败提示。此时仍可点击原链接前往对应平台查看；稍后也可以重新编辑并保存进行重试。

系统不会保存第三方账号、Cookie、验证码或媒体文件，也不会绕过平台的登录、风控、版权或嵌入限制。
