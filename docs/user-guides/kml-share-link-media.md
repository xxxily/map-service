# KML 点位分享链接媒体使用说明

## 支持范围

当前首期支持抖音公开视频分享链接。可以粘贴抖音应用复制出来的完整分享文案，也可以粘贴以下地址：

- `https://v.douyin.com/<短码>/`
- `https://www.douyin.com/video/<视频 ID>`
- `https://www.iesdouyin.com/share/video/<视频 ID>`
- `https://open.douyin.com/player/video?vid=<视频 ID>`

私密、已删除、下架、地区受限或抖音不允许嵌入的视频可能无法播放。

## 添加到点位

1. 登录 map-service，并确认账号具有 KML 编辑权限。
2. 在 2D 或 3D 地图中新增点位，或打开已有点位后选择“编辑”。
3. 把完整抖音分享文案粘贴到“描述”中，可以同时填写自己的说明文字。
4. 点击保存。系统会识别链接，并把可用视频转换为点位媒体。
5. 打开点位弹窗中的媒体卡片或“查看详情”，即可在统一媒体预览器中播放。

抖音短链接需要服务端展开，通常会比普通点位保存多等待片刻。已经包含视频 ID 的详情地址可以直接转换。

## 预览显示

- iframe 水平方向会占满媒体预览区域，不再设置固定最大宽度或左右留白；当页面高度小于可用区域时，只做上下居中。
- 抖音播放器会按当前 iframe 视口自适应宽高。播放器主体和播放控制条完整保留，额外的白色底部跳转栏不再占用站内预览区域。
- 关闭媒体预览后，可以直接再次点击点位 popup 中的同一张媒体卡片重复打开，无需先关闭并重新打开点位 popup；收缩小窗、恢复和打开原始页面功能保持不变。
- 第三方页面内部的颜色和布局由对应平台控制，站点不会跨域修改其页面内容。平台加载失败时仍可使用“原始页面”前往查看。

## 编辑和删除

- 再次编辑点位时，只会看到原分享文案和自己的说明，不会看到系统生成的 iframe 标记。
- 不修改分享链接直接保存时，会复用已有解析结果，不会重复添加媒体。
- 从描述中删除分享链接并保存后，对应媒体也会移除。
- 同一个视频链接出现多次，只展示一个媒体项。

## 失败处理

如果短链接超时、平台拒绝访问、视频不可用、账号未登录或没有写权限，点位仍会保存原始描述，并显示转换失败提示。此时仍可点击原链接前往抖音查看；稍后也可以重新编辑并保存进行重试。

系统不会保存抖音账号、Cookie、验证码或视频文件，也不会绕过抖音的登录、风控和版权限制。
