# KML 要素整理使用说明

## 编辑时移动或复制

1. 在 2D 或 3D 地图中打开点位、线段或区域的简介，选择“编辑”。
2. 当账号中有多个可写 KML 时，在“所属 KML”中选择目标文件。
3. 保存后选择“移动”或“复制”。

“移动”会从原文件移除要素并保留原 ID；“复制”会保留原文件内容，在目标文件创建新 ID 的副本。编辑弹窗中修改的名称、描述和点位图标会应用到目标要素；复制时原要素内容不变。

## 在管理面板中拖拽

- 展开个人 KML 后，可以拖动要素左侧手柄进行排序。
- 拖到同一文件中的另一个要素时，会插入到该要素之前；拖到文件卡片或列表空白区域时，会移到末尾。
- 拖到其他个人 KML 后，系统会询问移动或复制；取消不会修改任何文件。
- 目标文件会自动展开，但不会自动改变其显示或隐藏状态。

当实时轨迹列表只展示经过视口或缩放过滤的部分要素时，拖拽排序会暂时关闭，避免局部列表改变全量顺序。此时仍可通过编辑弹窗移动或复制单个要素。

## 批量整理要素

1. 展开“个人图层”分区，点击标题右侧的批量按钮。
2. 在可写个人 KML 中勾选需要处理的点位、线段或区域；点击要素内容仍可定位，使用左侧选择框切换选中状态。
3. 可使用“全选”选择当前面板显示的全部要素，或使用“反选”切换当前显示要素的选择状态。
4. 点击“操作”，选择移动、复制或删除。
5. 移动或复制时选择目标 KML；删除会先要求确认。

全选和反选只处理当前面板实际显示的可写要素，不会把视口过滤隐藏的记录偷偷加入批次。批量移动保留原要素 ID，复制会生成新的要素 ID，删除、移动和复制均作为一次可撤销操作保存。批量模式下拖拽排序会暂时关闭；点击取消或关闭面板会退出批量模式。

公共、分享和只读 KML 不提供批量入口，也不能作为批量目标。

## 权限与同步

- 只有可写的个人 KML 显示拖拽入口，并可作为目标。
- 公共 KML、分享页面和只读账号不能移动、复制或排序要素。
- 登录账号的操作会通过现有 KML 同步保存；发生版本冲突时按页面提示处理恢复草稿，不会静默覆盖服务器内容。
- 移动、复制和排序均支持现有撤销/重做快捷键。

## 分享发布

个人 KML 的编辑保存与外部分享发布是两个步骤。修改已加入分享的点位、线段、区域、顺序或说明后，个人空间会保存新版本，但外部链接继续使用上一次已发布快照。

进入“个人空间 -> 我的分享”可查看待同步数量。确认内容后点击“同步内容”，系统会更新外部分享并重新计算空间受限范围；同步失败不会覆盖原分享内容。
