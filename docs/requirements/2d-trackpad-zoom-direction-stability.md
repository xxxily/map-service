# 2D macOS 触摸板缩放方向稳定性需求

> 状态：已实现，待随 v1.5.23 发布
> 适用范围：2D Leaflet 地图；不改变 3D Cesium 相机交互

## 1. 背景

macOS 触摸板的双指捏合通常由浏览器合成为带 `ctrlKey` 的 `wheel` 事件，双指滚动则产生普通 `wheel` 事件。两类事件还可能在同一时间窗口内交错，捏合结束后也可能带有普通滚动惯性尾流。Leaflet 默认在一个 debounce 窗口内把所有事件直接累加，旧方向事件会压过最新方向，表现为放大/缩小反向或连续操作方向跳变。

## 2. 目标与边界

- 双指捏合和双指滚动的缩放方向始终与用户输入一致。
- 不同输入模式切换时建立明确的手势边界，不把上一手势的累计量带入下一手势。
- 捏合结束后的普通滚动惯性不得反向覆盖捏合结果。
- 连续滚轮输入仍需及时合并，不能因为修复方向而丢失有效缩放。
- 保留 Leaflet 的 `zoomAnimation`、`fadeAnimation`、`markerZoomAnimation` 和旧层级瓦片兜底；不得通过关闭动画、禁用 WebGL/3D 或裁剪 KML 内容解决问题。
- 只调整 2D Leaflet 滚轮路径；移动端原生双指触控、Shift 旋转和 3D 页面保持原有逻辑。

## 3. 功能要求

### 3.1 输入识别

将 `deltaMode=0` 且 `ctrlKey=true` 的精细滚轮事件识别为 `pinch`，其余有效滚轮事件识别为 `scroll`。方向以 Leaflet 归一化后的 delta 符号为准，保持 Leaflet 的“正值放大”语义。

### 3.2 手势边界

- 首个有效事件开启新手势。
- 输入模式改变或方向改变时，清零 Leaflet `_delta`、取消旧计时器并从当前事件重新累计。
- 同模式同方向事件在 `120ms` 内连续到达时继续累计；空闲超过该时间后开启新手势。
- 零增量、水平/深度滚动等无效事件不得改变状态。

### 3.3 捏合惯性隔离

最近一次 `pinch` 事件后的 `180ms` 内，忽略模式为 `scroll` 的普通惯性事件，不更新方向或累计量。保护期结束后，第一条普通滚动建立新的手势边界并正常缩放。忽略事件仍阻止其进入 Leaflet 缩放累计器。

### 3.4 动画与性能

- `zoomSnap` 设为 `0`，避免极小残余量被强制吸附为半级反向跳动；`zoomDelta` 保持 `0.5` 供按钮等离散控件使用。
- 缩放期间旧瓦片和旧渲染层必须继续可见，动画结束后才按 Leaflet 生命周期清理。
- 不在每个 wheel 事件中重建 KML 图层、解析媒体或刷新管理面板。

## 4. 实现约束

- 通过独立的 `src/map/trackpad-wheel-zoom.js` 纯状态机和 Leaflet `ScrollWheelZoom` 适配器实现。
- 适配器只在 Leaflet 原型可用且未安装补丁时生效；使用 Symbol 防止热更新或重复初始化造成多次包装。
- 事件被忽略或边界重置时不得改变地图中心、旋转角度或其他交互状态。
- 未来升级 Leaflet 时必须重新确认 `_onWheelScroll` 的内部字段契约（`_delta`、`_timer`、`_startTime`）。

## 5. 测试与验收

自动化测试覆盖：

- 同一滚动手势反向输入会清除旧累计量；scroll 到 pinch 会建立新边界。
- 捏合后的普通惯性在保护期内被忽略，保护期结束后普通滚动可用。
- 空闲超时、零增量、时间戳倒序、重复安装和 Leaflet 适配器行为。
- 最终地图配置保持三项动画开启、`zoomSnap=0`。

浏览器验收覆盖：

- 合成普通滚动后立即捏合，以及捏合后普通惯性尾流，最终缩放方向均正确。
- 跨整数层级快速缩放时，动画期间 `_animatingZoom` 和 `.leaflet-zoom-anim` 存在，旧/新瓦片层均保持可见，不出现整屏白屏或撕裂。
- 保护期结束后可继续反向滚动；2D 桌面 Shift 旋转、移动端双指缩放和 3D 页面无回归。
