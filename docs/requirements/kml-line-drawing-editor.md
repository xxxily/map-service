# KML 线段绘制编辑器

状态：已实现，v1.5.60 发布。

## 目标

在 KML 数据管理中为可写 KML 文件提供“新增线段”入口。用户可以在地图上连续采集点位，实时预览线段，调整点位后再合并保存为一个标准 KML `LineString` 要素。

## 交互契约

- KML 文件操作区提供图标按钮 `data-kml-action="add-line"`，只对当前可写且已启用的文件显示。
- 编辑状态使用独立工具栏，提供撤销、重做、删除选中点、清除全部、保存和取消操作；快捷键为 `Ctrl/Cmd+Z`、`Ctrl/Cmd+Y`、`Delete/Backspace` 和 `Esc`。
- 地图点击连续添加临时点位。临时点位可选中、拖拽移动或删除；至少两个点才能合并。
- 已保存的 `LineString` 可从 KML 要素列表的编辑按钮重新进入同一顶点编辑器，保存时更新原要素 ID 和坐标，不会重复创建线段。
- 编辑器不关闭 Leaflet 地图拖拽和缩放，不绘制辅助线模式中的连续十字虚线；鼠标位置只显示实线十字准星。
- 编辑中的折线始终实时预览，合并前修改不会写入 KML 文件；取消或关闭编辑器会清理临时图层。
- 辅助线模式与线段编辑互斥，编辑器快捷键优先于 KML 面板的普通快捷键。

## 数据契约

- 合并后追加一个 `type: "LineString"` 要素，坐标顺序与用户添加点位顺序一致。
- 地图上的 GCJ-02 坐标按目标文件的 `coordCorrection` 设置转换回存储坐标；导出、账号同步和公共 KML 编辑继续复用现有保存链路。
- 线段完整保留连续顶点，不额外生成 Point 要素；后续如需将线段拆回点位，应另行设计数据迁移和编辑交互。

## 验证

- 状态模型覆盖连续加点、选中、拖拽、删除、清除、撤销和重做。
- 源码契约覆盖工具栏动作、地图拖拽约束、LineString 写入和坐标转换。
