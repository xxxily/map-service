# 2D 移动端双指旋转稳定性需求

> 状态：已实现，随 v1.5.68 发布
> 适用范围：`index.html` 的 Leaflet 2D 地图；不改变 `3d.html` 的 Cesium 相机交互

## 1. 背景

2D 地图同时支持双指捏合缩放和双指旋转。现有 `leaflet-rotate` 触摸处理使用
`atan(x / y)` 并按象限补角，角度在负 Y 象限存在不连续点；部分静止捏合会被计算成
接近 180 度的旋转。浏览器在连续触摸事件中也可能调整 `TouchList` 顺序，直接读取
`touches[0]`、`touches[1]` 会进一步制造方向跳变。

## 2. 行为目标

- 保留现有 30 度旋转触发阈值，不增加阈值，不新增锁定/解锁图标。
- 单纯捏合、手指轻微抖动和触摸列表重排不得改变地图 bearing。
- 用户确实旋转超过阈值后，旋转立即进入连续响应；首次越过阈值不产生角度突跳。
- 缩放仍使用 Leaflet 原生连续缩放、中心计算和动画生命周期。
- 只修正 2D Leaflet 触摸路径，3D Cesium 页面保持独立实现。

## 3. 交互契约

### 3.1 角度

- 双指向量使用两个触摸点的容器坐标差值。
- 使用 `Math.atan2(vector.x, vector.y)` 保留四象限信息。
- 当前角度与起始角度的差值归一化到 `[-PI, PI]`，始终沿最短方向计算。

### 3.2 触摸身份

- `touchstart` 时保存两个触摸点的 `identifier`。
- 后续 `touchmove` 按 identifier 找回对应触摸点，不依赖 TouchList 的数组顺序。
- 任一已捕获触摸点缺失时，本次事件安全忽略，不猜测新的手指身份。

### 3.3 阈值与软启动

- 旋转差值绝对值小于 30 度时只执行捏合缩放，不提交 bearing。
- 首次达到 30 度时，将当前角度和当前 bearing 重新作为基线；从下一采样开始提交增量，
  避免阈值触发瞬间跳转。
- 触摸结束后清理手势身份和阈值状态，下一次双指手势重新初始化。

## 4. 实现边界

- 逻辑位于 `src/map/touch-rotation.js`，由 `src/main.js` 显式安装。
- 不修改 `src/3d.js`、`3d.html` 或 Leaflet 的缩放动画配置。
- 适配器使用 Symbol 防止重复安装；升级 `leaflet-rotate` 时需重新核对其 handler 内部字段契约。

## 5. 验收

- Node 回归测试覆盖角度跨界、负 Y 静止捏合、TouchList 重排、30 度软启动、缩放连续性和
  重复安装。
- 移动端浏览器验证覆盖真实 `index.html` Leaflet 实例的双指捏合、旋转和触摸列表重排；
  3D 页面不加载该适配器。
