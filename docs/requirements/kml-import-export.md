# KML 导入导出

## 背景和目标

地图需要支持导入外部 KML 文件，在当前底图上查看、管理和导出点、线、面要素。KML 标准坐标通常为 WGS84，经纬度直接叠加到高德底图时会出现位置偏差，因此需要提供坐标纠偏能力。

## 范围内事项

- 支持导入 `.kml` 文件中的 `Placemark` 点、线、面要素。
- 导入后默认开启坐标纠偏，将 WGS84 坐标按高德底图使用的 GCJ-02 坐标显示。
- 用户可以在导入前关闭默认纠偏，也可以对已导入的单个 KML 文件切换纠偏显示。
- 用户可以按 KML 文件启用或禁用显示；禁用后该文件的所有图层从地图移除，避免多个 KML 叠加造成界面凌乱或渲染压力过高。
- KML 文件列表默认仅展示文件名称、要素数量和启用状态控制；坐标纠偏、新增点、导出、删除等文件级操作应收纳到展开区域内。
- 内部存储和导出保持 KML 标准经纬度，不将 GCJ-02 显示坐标直接写入导出的 KML。
- 在纠偏开启时，新增点和拖拽点位需要先从地图显示坐标反算回 WGS84 后再保存。
- 点要素有真实名称时才在地图上显示名称标签，名称过长时需要截断和限宽，避免遮挡地图主体内容；名称为空时只显示图标。
- 保留点位 `description` 中的 HTML/CDATA 内容、`styleUrl` 语义提示和受控的 `markerIcon` 扩展；包含图片、视频、音频、720 云或其他受控页面元素的点位使用对应媒体图标，详情按富媒体安全规则展示。

## 范围外事项

- 不支持 KMZ 解压导入。
- 不完整保留 KML 原始视觉样式、文件夹层级和未登记扩展字段；目前明确保留媒体点位识别所需的 `styleUrl` 提示，以及项目扩展 `map-service:marker-icon`。未知扩展值忽略，不发起远程图标请求。
- 不实现复杂几何编辑，仅保留现有点位拖拽和属性编辑能力。

## 数据模型

每个导入的 KML 文件在本地保存：

- `id`：本地文件 ID。
- `name`：文件名。
- `coordCorrection`：坐标显示策略，`wgs84-to-gcj02` 表示开启纠偏，`none` 表示不纠偏。
- `enabled`：是否在地图上显示该 KML 文件，缺省按启用处理以兼容旧数据。
- `features`：要素数组，坐标均按 KML/WGS84 保存。

单个 Feature 除 `id`、`type`、`name`、`coordinates` 外，还可包含：

- `description`：保留原始描述文本或 HTML 片段；展示时不得原样注入页面。
- `styleUrl`：可选的 KML 样式引用，仅作为图片、视频、音频等点位类型提示，不承诺还原完整原始样式。
- `markerIcon`：仅 Point 可选的内置图标枚举：`pin`、`star`、`flag`、`viewpoint`、`camera`、`campsite`、`food`、`lodging`、`parking`、`warning`、`heart`、`home`、`water`、`restroom`、`hospital`、`shop`、`charging`、`bus`、`train`、`bicycle`、`hiking`、`summit`、`waterfall`。未填写表示自动识别内容。
- Point 的 `name` 可为空或只包含空白；规范化后保存为空字符串，不自动填充“未命名点位”。

导出 `markerIcon` 时写入以下 KML `ExtendedData`，导入只接受上述枚举；`auto` 仅为界面选项，不写入 KML：

```xml
<ExtendedData>
  <Data name="map-service:marker-icon">
    <value>viewpoint</value>
  </Data>
</ExtendedData>
```

## 验收标准

- 使用高德底图时，默认导入的 WGS84 KML 点位应与底图位置对齐。
- 关闭纠偏后，同一 KML 文件按原始坐标显示。
- 对开启纠偏的文件新增或拖拽点位后，导出的 KML 仍能在 Google Earth 等标准 KML 工具中按正确位置使用。
- 导出文件不受当前纠偏开关影响，始终输出标准 KML 经纬度。
- 导入 KML 后有名称的点位无需点击图标即可看到名称；无名称点位只显示图标，长名称不会大面积覆盖地图。
- 禁用某个 KML 文件后，该文件的点、线、面和点位名称不再显示；再次启用后可以恢复显示，导出内容不受启用状态影响。
- KML 列表在折叠状态下保持简洁，展开单个文件后才能看到该文件的纠偏、新增、导出、删除和要素列表。
- `description` 中包含无文件扩展名的 `<img>`、`<video>`、`<audio>` 等媒体 URL 时，仍按标签语义正确分类和展示；对应 2D/3D 点位无需点击即可从图标识别媒体类型。
- 含 `markerIcon` 的 KML 导出后重新导入，点位图标保持不变；未知枚举、非 Point 上的图标和远程图标 URL 均被忽略或按接口校验失败处理，不进入持久化数据。
