# KML 媒体预览与 3D 地图界面精简需求

> 状态：第一版已发布（v1.5.19）
> 更新日期：2026-08-18

## 背景与目标

KML 富媒体点位在移动端已经采用“单击直接浏览、长按进入操作弹层”的交互，但桌面端仍需先打开弹层再进入媒体浏览，形成不必要的端侧差异。媒体大窗内部的标题、导航、操作按钮和缩略轨道也存在明暗状态不一致、触摸后底色滞留及 iframe 缩略项辨识度不足的问题。

3D 页面同时展示 Cesium 品牌图标、独立地形状态和渲染质量选择面板，占用地图可视空间。日常使用应以地图内容为主，只保留必要且简洁的运行状态。

本次目标是统一 KML 媒体点位交互，建立稳定一致的媒体浏览视觉状态，并精简 3D 页面辅助信息。

## 功能需求

### 1. 媒体点位交互统一

- 2D 与 3D 页面、桌面与移动环境采用同一交互：
  - 单击包含可预览媒体或资源集合的点位，直接打开大窗浏览。
  - 长按主按钮或触摸点位，打开点位操作弹层。
- 长按识别期间移动超过容差、开始拖拽、发生多指操作或指针取消时，必须取消长按。
- 长按成功后必须抑制同一次手势产生的单击事件，不能同时打开操作弹层和媒体大窗。
- 不包含可预览内容的普通点位维持原有单击操作弹层行为。

### 2. 媒体大窗视觉状态

- 标题区域、左右导航、缩略轨道、缩略轨道开关、外部打开、小窗和关闭按钮统一使用浅色透明玻璃底。
- 默认、悬停、焦点和按下状态不得切换为深色底。
- 激活态只通过墨绿色边框、文字色或轻量描边表达，不改变控件底色。
- 触摸设备不得因粘滞 `hover` 或焦点状态导致按钮长期变暗。
- PC 的外部打开入口只显示图标，通过 `aria-label` 和 `title` 保留可访问名称。

### 3. 缩略轨道 provider 图标

- 图片继续显示真实缩略图。
- 已识别 provider 的 iframe 页面使用与地图点位一致的 provider 图标，例如抖音和 720 云。
- 未识别 provider 的 iframe、视频和音频继续使用稳定的通用类型图标。
- provider 图标只使用项目内置、受控 SVG，不加载任意远程图标。
- 缩略轨道必须保留全部媒体项、准确数量和完整可滚动访问路径，不得以性能优化为由裁剪项目。

### 4. 3D 页面精简

- 隐藏 Cesium 品牌图标，但保留地图和数据服务商要求的文字署名。
- 不再创建可见的渲染质量选择面板；默认沿用 `auto`，由受控配置决定实际质量档。
- 将地形状态合并到左下角经纬度和海拔信息中，使用简短状态，例如“真实地形 1.18×”“地形加载中”“平面模式”。
- 正常状态不再占用右上角空间；地形异常时仍保留非阻塞“重试”入口。
- 详细地形状态仍应通过无障碍文本或日志保留，不能因界面精简而丢失诊断能力。

## 非功能需求

- 不改变 KML 媒体解析、安全白名单、分享权限和资源集合分页规则。
- 不增加第三方依赖，不使用浏览器原生阻塞弹窗。
- 新交互必须覆盖 Leaflet 2D 和 Cesium 3D 两条实现路径。
- 样式调整不得破坏媒体关闭释放、移动端返回手势、图片缩放、全量缩略项和小窗模式。

## 验收标准

1. 桌面端单击媒体点位直接进入大窗，按住约 650ms 打开点位操作弹层；同一手势不会同时触发两者。
2. 移动端原有单击与长按行为不回退。
3. 大窗标题、导航、操作按钮和缩略轨道始终为统一浅色透明底；按下后只保留墨绿色边框反馈。
4. PC 外部打开入口只有图标，键盘和读屏仍能识别其用途。
5. 720 云和抖音 iframe 缩略项显示对应 provider 图标，未知页面显示通用页面图标。
6. 3D 页面不显示渲染质量面板和 Cesium 品牌图标；经纬度信息后显示简短地形状态。
7. 地形进入 fallback 或 degraded 状态时仍可执行手动重试。
8. `npm run check`、相关自动化测试、完整测试和生产构建通过。
